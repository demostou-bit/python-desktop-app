## 収録している主なサンプルプログラム

テキストに沿って作成したサンプルコード群です。

### アプリケーション例
- **割り勘計算アプリ** (`warikan_app.py`): 料金と人数から割り勘金額を計算するツール
- **クイズアプリ** (`quiz_app.py`): CSVファイルから問題を取り込んで出題するクイズ
- **デスクトップタイマー** (`timer_desktop.py`): 時間を計測するタイマー機能
- **蔵書管理/データベース連携アプリ** (`collection_app.py`): データを保存・管理するアプリ
